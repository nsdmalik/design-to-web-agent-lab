# Contributing

Start with the README and run `python3 -m unittest -v`. Open an issue describing the behavior you want to change before a substantial addition. Include a small, fictional example and a regression test for bug fixes.

Keep the core dependency-free. Document changes to data contracts, validation rules, and public interfaces. Never submit credentials, customer exports, private schemas, or code you do not have permission to share.

Use descriptive commits and keep pull requests focused. Contributions are provided under this repository's MIT license.
